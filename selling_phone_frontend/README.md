# Selling Phone Frontend

Frontend React tach rieng khoi backend Spring Boot.

## Yeu cau

- Node.js 20+
- Backend chay tai `http://localhost:8080`

## Cai dat

```bash
npm install
```

Tao file `.env` tu `.env.example`:

```env
VITE_API_BASE_URL=http://localhost:8080
```

## Chay dev

```bash
npm run dev
```

Mac dinh Vite chay tai `http://localhost:5173`, backend hien da cho phep CORS port nay.

## Build

```bash
npm run build
```

Thu muc nay co the day len mot Git repo rieng.
